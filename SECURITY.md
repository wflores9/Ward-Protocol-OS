# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities to:
**security@wardprotocol.org**

Do not open public GitHub issues for security vulnerabilities.
We aim to acknowledge reports promptly. Response times and remediation schedules depend on severity and available maintainers; no contractual response-time commitment is implied.

## Scope

- ward/ Python library
- Public repository code and documented interfaces (hosted endpoint availability is not asserted)
- Nine-check default validation logic
- ward_signed = False invariant
- TypeScript SDK (@wardprotocol/sdk)

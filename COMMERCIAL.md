# Ward Protocol — Licensing and Commercial Inquiries

Ward publishes source code and technical documentation for evaluation and independent review. **The repository currently has no root LICENSE file.** Package metadata or prior README claims must not be treated as a substitute for an explicit repository license. Licensing terms need founder/legal confirmation before being represented as granted.

Enterprise support, hosted services, certification, or production SLAs **must not be assumed available** from this repository. Any such offering, scope, pricing, security obligations, and service levels require a separate written agreement.

Ward never holds signing keys or customer assets and does not sign, submit, or settle transactions. `ward_signed = false`.

For inquiries, use the contact channel published at [wardprotocol.org](https://www.wardprotocol.org).
